## 3. Does tolerating repetition pay? (ADR-0028)

The category-affinity oracle knows each search user's mean reward per category and shows a random available single-tag video of the chosen category. Its **full cycle** mode shows every rotation category once before any repeat; **strict** revisits a category as soon as it leaves the 9-item window; **free** repeats a category as often as the setting allows. **Baseline (decision field):** the full-cycle policy, because the quit parameters are hidden from policies, so a policy that has learned nothing cannot run window-based rotation; its only safe option is the full cycle through all 29 rotation categories.
